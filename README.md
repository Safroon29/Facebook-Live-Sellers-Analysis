# Facebook-Live-Sellers-Analysis
Data Analysis and K-Means Clustering on the Facebook Live Sellers in Thailand Dataset using Python.

## Overview

This project analyzes the **Facebook Live Sellers in Thailand Dataset** using Python and Machine Learning.

The objective is to understand user engagement patterns by analyzing reactions, comments, shares, posting time, and post types. K-Means clustering is used to group posts with similar engagement characteristics.

---

## Dataset

- **Source:** UCI Machine Learning Repository
- **Records:** 7050
- **Features:** 13 (after preprocessing)

8. PCA Visualization
9. Business Insights

---

## Key Findings

- Upload time influences audience engagement.
- Reactions, comments, and shares are positively correlated.
- Four optimal clusters were identified using the Elbow Method.
- Cluster analysis revealed different engagement patterns among Facebook posts.
